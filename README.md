# ❤️ L'Écho du Désir

Une expérience interactive pour deux personnes construite en React.

## Objectif

L'Écho du Désir est un jeu immersif composé de défis progressifs destinés à renforcer la complicité, la communication et la découverte mutuelle.

Le projet fonctionne directement depuis GitHub Pages sans installation.

---

## Fonctionnalités

- Système de Jetons Désir (JD)
- Défis progressifs
- Deux phases de jeu
- Sauvegarde automatique
- Synchronisation Duo (version future)
- Design premium mobile
- Fonctionnement hors installation

---
